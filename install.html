QBiz Kho

Quản lý kho trên Web, Android và iPhone bằng cùng một tài khoản và dữ liệu.

ANDROID

Cài trên Android

Mở trang này bằng Chrome rồi chọn Cài ứng dụng hoặc Thêm vào màn hình chính.

IPHONE / IPAD

Cài trên iPhone

1. Mở trang bằng Safari.
2. Bấm Chia sẻ.
3. Chọn Thêm vào Màn hình chính.
4. Bật Mở dưới dạng ứng dụng web nếu được hỏi.
WEB / PC

Dùng ngay trên máy tính

Mở trực tiếp QBiz Kho trên trình duyệt hoặc cài thành cửa sổ ứng dụng bằng Chrome/Edge.

Lưu ý: website phải chạy HTTPS để trình duyệt cho phép cài PWA đầy đủ.
